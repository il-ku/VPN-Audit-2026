# Инструкция по развертыванию узла (Сервер А)

## Требования
- Чистая операционная система Ubuntu (поддерживается 22.04 / 24.04 / 26.04).
- Права суперпользователя (root).
- Свободный TCP-порт 443.

## Запуск одной командой
1. Скопируйте файл `install.sh` на сервер.
2. Сделайте его исполняемым и запустите:
   ```bash
   chmod +x install.sh
   ./install.sh
